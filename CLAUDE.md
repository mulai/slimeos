# Slime OS

Before starting work in this repo, read `.claude/FUTURE_SESSION_NOTES.md` — it holds
whatever was left pending from the last development session. If it says "nothing pending,"
there's nothing to check. Keep it lean: prune items once they're done.

Repo conventions (commits, OTA version bumps, product rules): `docs/dev-conventions.md`.
In a cloud session there is no local memory or FUTURE_SESSION_NOTES.md and no access to
devices, Brains or the hub; work from the repo and GitHub issues and finish with a PR.
